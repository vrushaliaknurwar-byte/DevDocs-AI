About DevDocs AI

DevDocs AI turns complex codebases into clear, interactive architectural documentation. Using native AST and Tree-Sitter grammars, it parses Python, JavaScript, and TypeScript into syntactic functions and classes, embeds them into a 768-dimensional vector space with Google Gemini, and performs high-speed semantic retrieval directly backed by PostgreSQL and pgvector.

Features

⚡

Shallow Ingestion

Lightweight depth-1 cloning that filters out binaries and node_modules in seconds.

🧠

AST Chunking

Accurate class and function boundaries parsed with language-native grammar.

🎯

Verified Citations

Every answer links straight to the source file with 1-indexed start and end line ranges.

Frequently Asked Questions

What languages does DevDocs AI currently parse?

In Phase 1, DevDocs AI features syntax-aware chunking for Python (.py) using the native ast engine and JavaScript/TypeScript (.js, .jsx, .ts, .tsx, .mjs, .cjs) using tree-sitter.

How does the citation system work?

When you ask a question, your query is embedded with Gemini, matching the top 5 code chunks in PostgreSQL via pgvector cosine distance. Each chunk preserves its exact file path and line numbers, returned as citation chips.

Are my private repositories supported?

Phase 1 supports any public GitHub repository URL. Future phases will introduce personal access tokens and OAuth for private organization repos.
